# 00. 교재 소개 과제 해설

[본문으로 돌아가기](../../00_Introduction.md#실습-과제)

이 챕터의 과제는 정답 코드가 아니라 환경과 학습 목표를 확인하는 체크리스트입니다.

## P0-C00-P1 · Rust 도구 버전

```bash
rustc --version
cargo --version
```

두 명령이 종료 코드 0으로 끝나고 버전 문자열을 출력하면 설치된 것입니다. `rustc`와 `cargo`가 서로 다른 toolchain을 가리키지 않는지 `rustup show active-toolchain`도 함께 확인할 수 있습니다.

## P0-C00-P2 · 설치 확인

### 확인 기준

- `rustc`와 `cargo` 모두 명령을 찾을 수 있다.
- 교재가 요구하는 Rust 버전 이상이다.
- 터미널을 새로 열어도 같은 명령이 동작한다.

명령을 찾을 수 없다면 설치 직후 터미널을 다시 열어 PATH 변경을 반영합니다.

## P0-C00-P3 · 학습 결과물 선택

정답은 없습니다. 다음 세 항목을 한 문장씩 기록하면 이후 과제의 범위를 정하기 쉽습니다.

- 만들고 싶은 결과물
- 먼저 학습할 Part
- 완료를 판단할 수 있는 화면 또는 동작

예: “Part 2부터 진행해 키보드 이동과 충돌, 점수, 게임오버가 있는 2D 게임을 완성한다.”

## P0-C00-A1 · Bevy 설계 목표 조사

공식 소개에서 한 항목을 고른 뒤 다음 형식으로 정리합니다.

1. 선택한 설계 목표
2. 자신의 프로젝트에 중요한 이유
3. 그 목표가 만드는 장점
4. 예상되는 trade-off

문구를 그대로 복사하는 것보다 실제 프로젝트 요구사항과 연결해 설명했는지가 판단 기준입니다.
