# 04. 개발 환경 과제 해설

[본문으로 돌아가기](../../04_DevelopmentEnvironment.md#실습-과제)

## P0-C04-P1 · 설치 버전 확인

다음 두 명령의 출력을 기록합니다.

```bash
rustc --version
cargo --version
```

두 명령을 찾을 수 없다면 Rust 공식 설치 페이지에서 `rustup` 설치부터 확인합니다. 이미 03장의 창이 열렸다면 추가 설치는 필요하지 않습니다.

## P0-C04-P2 · 프로젝트가 요구하는 버전

루트 `Cargo.toml`의 `[workspace.package]`와 `[workspace.dependencies]`를 확인합니다.

- `rust-version`: 워크스페이스가 요구하는 최소 Rust 버전
- `bevy`: 교재가 사용하는 Bevy 버전

## P0-C04-P3 · 검사와 실행 비교

`cargo check -p hello_bevy`는 코드 검사를 마치지만 창을 열지 않습니다. `cargo run -p hello_bevy`는 링크까지 마친 뒤 03장의 창을 엽니다. 두 명령이 성공하면 필수 환경 점검은 완료입니다.

## P0-C04-A1 · 빠른 링커

설정 전후의 **두 번째 빌드** 시간을 같은 조건에서 비교합니다. 첫 빌드는 의존성 다운로드와 전체 컴파일이 포함되어 공정한 비교가 아닙니다.

| 항목 | 기록 |
|---|---|
| 운영체제·CPU | 재현 환경 |
| 기본 링커 두 번째 빌드 | 시간 |
| 대체 링커 두 번째 빌드 | 시간 |
| 같은 소스 변경 여부 | 예/아니오 |
| 채택 여부와 이유 | 시간 차이·설정 복잡도 |

첫 빌드는 전체 의존성을 컴파일하므로 비교 대상에서 제외합니다. 현재 링크 시간이 불편하지 않다면 이 과제를 수행하지 않아도 됩니다.
