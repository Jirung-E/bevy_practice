# 34A 선택형 과제 해설

카메라 보간은 두 방향을 똑같이 느리게 처리하면 안 됩니다.

- 장애물이 새로 나타나 거리가 짧아질 때: 즉시 줄여 벽 관통 방지
- 장애물이 사라져 거리가 길어질 때: 서서히 늘려 화면 튐 방지

Collision Layer 과제에서는 플레이어 이동을 막는 Collider와 카메라를 막는 Collider가 반드시 같지는 않다는 점을 먼저 정하세요. 얇은 풀, 트리거 Volume과 반투명 장식물은 캐릭터 충돌 정책과 카메라 가림 정책이 다를 수 있습니다.

Shape cast로 확장할 때도 시작점, 방향, 최대 거리와 자기 Entity 제외 원칙은 동일합니다. 바뀌는 것은 선 대신 부피가 이동한다는 점입니다.
