# 33. 애니메이션 과제 해설

[본문으로 돌아가기](../../33_Animation.md#실습-과제)

## P5-C33-P1 · 흔들림 값

진폭과 주파수를 하나씩 바꾸고 루트가 아니라 시각 모델 자식에 적용합니다. Collider까지 흔들면 접지 판정이 불안정해집니다.

## P5-C33-P2 · 달리기 주파수

실제 수평 속도에서 Idle/Walk/Run 상태를 계산하면 외력이나 감속 중에도 표현이 자연스럽습니다.

## P5-C33-P3 · 반대 위상 팔다리

왼팔·오른다리와 오른팔·왼다리를 같은 위상 그룹으로 묶고 한 그룹에 `sin(t)`, 다른 그룹에 `-sin(t)`을 적용합니다.

## P5-C33-A1 · glTF와 0.2초 전환

Idle/Walk 클립을 AnimationGraph 노드로 등록하고 상태 변화 때 0.2초 전환을 요청합니다. 수행 예제는 경과 0, 0.1, 0.2초의 혼합 가중치가 0, 0.5, 1인지 검사합니다.

에셋 문서에는 원본 URL, 제작자, 라이선스 이름·버전, 수정 여부, 재배포 조건을 기록하세요. 무료 다운로드와 프로젝트 재배포 허용은 같은 뜻이 아닙니다. root motion은 물리 루트와 애니메이션 중 이동 소유자를 명시해야 합니다.
