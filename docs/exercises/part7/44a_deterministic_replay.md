# 44A 선택형 과제 해설

checksum은 디버그 위치를 찾기 위한 보조값이지 원래 State를 대신하지 않습니다. 중요한 정수 필드를 정해진 순서로 hash하고, `HashMap`이나 Query 순회 순서를 그대로 hash하지 마세요.

실제 입력 기록은 물리 키 상태 전체보다 시뮬레이션이 소비한 `PlayerCommand`를 저장하는 편이 장치와 키 설정에 독립적입니다. 리바인딩 전후에도 같은 Move·Fire 명령을 재생할 수 있습니다.

리플레이 헤더에는 최소한 다음 값이 필요합니다.

- 형식 버전과 게임 빌드 버전
- Fixed tick rate
- 맵 또는 초기 State 식별자
- RNG seed
- 입력 frame 수

호환되지 않는 기록을 억지로 재생해 우연히 그럴듯한 결과를 만드는 것보다 명확히 거부하는 편이 안전합니다.
