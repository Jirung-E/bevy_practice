# 27. Camera3d 과제 해설

[본문으로 돌아가기](../../27_Camera3d.md#실습-과제)

## P4-C27-P1 · 공전 반지름 비교

반지름 5에서는 작은 움직임도 화면 변화가 크게 보이고, 15에서는 장면 전체를 보기 쉽습니다. near/far plane과 줌 제한도 장면 크기에 맞춰 함께 확인합니다.

## P4-C27-P2 · 왼쪽 버튼 공전

입력 조건에 왼쪽 버튼을 추가하되 UI 조작과 충돌할 수 있다는 점을 확인합니다. 편집기형 앱은 viewport가 포인터를 소비했을 때만 공전시키는 편이 안전합니다.

## P4-C27-P3 · pitch 극점

제한을 없애면 up 벡터와 시선 방향이 거의 나란해지는 극점에서 방향이 뒤집히거나 불안정해질 수 있습니다. 제한은 임의의 불편이 아니라 좌표계 특이점을 피하는 장치입니다.

## P4-C27-A1 · 카메라 평면 pan

마우스 가로 이동에는 `-camera.right()`, 세로 이동에는 `camera.up()`을 곱해 focus에 더합니다. 월드 X/Y를 직접 쓰면 카메라가 회전했을 때 손 움직임과 화면 이동이 어긋납니다.

수행 예제는 정면 카메라에서 10픽셀 오른쪽, 5픽셀 아래 입력이 focus를 `(-1, 0.5, 0)`으로 옮기는지 검사합니다. pan 속도는 카메라 반지름이나 투영 크기에 비례시키면 줌 단계마다 체감이 일정합니다.
