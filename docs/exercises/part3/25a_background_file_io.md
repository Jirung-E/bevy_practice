# 25A 선택형 과제 해설

작업 수는 별도 카운터를 수동으로 증감하기보다 `Query<&ReadFileTask>`의 개수에서 구하면 제거 누락과 불일치하기 어렵습니다.

여러 요청의 완료 순서를 확인하려면 파일 이름과 요청 번호를 Task 결과에 함께 넣으세요. 최신 요청만 화면에 표시하려면 다음 두 값을 비교할 수 있어야 합니다.

- 애플리케이션이 현재 기대하는 최신 요청 번호
- 완료된 Task가 시작될 때 부여받은 요청 번호

번호가 다르면 결과를 버리되 Task Entity 정리는 수행합니다. 이것은 실행 중인 운영체제 파일 읽기를 중단하는 취소가 아니라, 더 이상 필요 없는 결과를 적용하지 않는 정책입니다.
