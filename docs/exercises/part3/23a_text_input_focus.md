# 23A 선택형 과제 해설

먼저 완성 예제를 복사하지 말고 다음 관찰 순서로 구현하세요.

1. 각 입력 Entity에 표시용 라벨을 식별할 Component나 `Name`을 붙입니다.
2. 제출 시 전체 입력 Query를 순회하지 말고 `InputFocus`가 가리키는 Entity 하나만 조회합니다.
3. 유효성 검사는 문자열을 바꾸는 System이 아니라 제출을 결정하는 System에 둡니다.

확인 기준은 마우스로 선택한 필드와 Tab으로 선택한 필드가 동일하게 동작하고, 한글 두 음절 이상을 조합해도 중간 자모가 제출 결과에 남지 않는 것입니다.

심화 과제에서는 `allow_newlines`를 켠 필드와 한 줄 필드를 구분하세요. 제출 단축키 판정은 편집 위젯의 문자열 처리와 별도의 System으로 유지합니다.
