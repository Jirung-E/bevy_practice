## 핵심 개념

### Bevy란?

Bevy는 Rust로 작성된 오픈 소스 데이터 중심 게임 엔진이자 앱 프레임워크입니다. 2D·3D 렌더링, 입력, 오디오, UI, 에셋 로딩 등의 기능을 플러그인으로 조합합니다.

Bevy의 중심에는 ECS(Entity Component System)가 있습니다.

- **Entity**: 게임 세계의 대상을 식별하는 ID
- **Component**: 대상이 가진 데이터
- **System**: 데이터를 읽고 변경하는 로직

예를 들어 플레이어는 하나의 Entity이고, 위치·체력·이동 속도는 Component이며, 키보드 입력으로 위치를 바꾸는 코드는 System입니다.

### 교재의 버전

이 교재는 2026년 7월 기준 최신 안정판인 Bevy 0.19를 사용합니다. Bevy는 아직 1.0 이전이므로 새 버전에서 API가 달라질 수 있습니다. 인터넷의 오래된 예제를 섞어 쓰지 말고, 이 저장소의 `Cargo.toml`과 공식 0.19 문서를 기준으로 진행하세요.

### 실습의 연결 방식

각 예제는 독립적으로 실행할 수 있지만 학습 내용은 이어집니다. Part 1에서 배운 Query와 Resource를 Part 2의 2D 게임에 적용하고, Part 7에서는 앞의 프로젝트를 Plugin과 모듈로 재구성합니다.

## 샘플 코드

아직 Bevy를 설치하지 않아도 다음 명령으로 현재 Rust 환경을 확인할 수 있습니다.

```bash
rustc --version
cargo --version
```

이 저장소에 예제가 추가된 뒤에는 루트에서 다음 명령으로 모두 검사합니다.

```bash
cargo check --workspace
```

## 코드 설명

- `rustc`는 Rust 소스 코드를 컴파일합니다.
- `cargo`는 프로젝트 생성, 의존성 다운로드, 빌드, 실행, 테스트를 담당합니다.
- `cargo check`는 최종 실행 파일을 만드는 과정을 줄여 코드가 컴파일되는지 빠르게 검사합니다.
- `--workspace`는 교재에 포함된 모든 예제 패키지를 검사합니다.

## 실습 과제

1. 터미널에서 `rustc --version`과 `cargo --version`을 실행하세요.

3. `docs/README.md`의 전체 커리큘럼을 읽고 가장 만들고 싶은 결과물을 하나 정하세요.
